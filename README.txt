捡手机模拟器 · 李羲承篇

运行：解压完整文件夹后，直接用浏览器打开 index.html。它是纯前端单机小游戏，不需要 Node.js、npm 或服务端。

OpenRouter AI：KakaoTalk、微信、Instagram 和 X 聊天都从浏览器直接请求 OpenRouter。API Key 与模型设置位于 index.html 的 OPENROUTER_API_KEY 和 OPENROUTER_MODEL 常量；当前使用 OpenRouter 免费模型路由。

音乐：在 Music 页面点选曲目即可播放 audio/ 文件夹中的 8 首 MP3。请保留 index.html、audio/、图片文件的相对目录结构。

玩家昵称在当前页面本地保存。进入手机后，上滑锁屏并输入 1015。
